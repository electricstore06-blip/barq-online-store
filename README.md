# BARQ Online Store

A responsive front-end online store for BARQ.

## Included
- Responsive homepage
- Search products
- Category filtering
- Product cards
- Working shopping cart using browser localStorage
- Mobile-friendly layout
- GitHub Pages ready

## Files
- `index.html` — store structure
- `style.css` — design and responsive layout
- `script.js` — products, search, categories and cart

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Important
This version is a front-end demo. The checkout button does not process real payments. Before taking real orders, connect it to your backend/order system and payment provider.
